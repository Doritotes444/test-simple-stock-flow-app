# `test-simple-stock-flow-app`

Frontend SPA desarrollado en **React 18 + TypeScript + Vite + Tailwind CSS** para el sistema **Simple Stock Flow**.

## Estructura
- `src/domain/types/` -> Tipos e interfaces del modelo de negocio.
- `src/infrastructure/api/` -> Clientes HTTP y conexión a la API REST.
- `src/application/hooks/` -> Custom Hooks para gestión de estado y lógica de UI.
- `src/presentation/` -> Componentes, Páginas y Enrutamiento.

## Desarrollo Local
```bash
npm install
npm run dev
```
O mediante Docker Compose desde el repositorio hermano `test-simple-stock-flow-infra`.
